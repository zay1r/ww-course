# Bug reports: Lesson 0.1

Fill in one report for each bug you fix. Bug hunt 6 has more than one bug, so it needs more than one report.

Copy this template for each bug:

```markdown
## Bug hunt N: file-name.js

- **Symptom:** what I saw. Paste the exact error message or the wrong output.
- **Expected:** what should have happened.
- **Kind of bug:** syntax, runtime or logic.
- **Cause:** why it happened, in one or two sentences.
- **Fix:** what I changed.
- **How I found it:** reading the error, labeled logs, the debugger, explaining it out loud…
```
